# 🌿 Centro Neurobiótico Ana Gámez

Bienvenida a mi proyecto personal y profesional: **Centro Neurobiótico Ana Gámez**, un espacio dedicado a brindar terapias de neurobiótica de forma natural, segura y efectiva, desde casa y completamente en efectivo.

Este sitio web será la plataforma principal para presentar mis servicios, agendar citas, mostrar promociones, y ofrecer productos que complementan la salud como **4Life** y **Ambit Energy**.

---

## 📁 Estructura del Sitio Web

| Sección                | Descripción |
|------------------------|-------------|
| **Inicio**             | Imagen de fondo en pantalla completa con filtro de transparencia. Efecto de aparición de colores tras unos segundos. Saludo animado estilo "máquina de escribir", de izquierda a derecha. |
| **About Neurobiótica** | Explicación de qué es la neurobiótica, beneficios, y una breve presentación personal de Ana Gámez. |
| **Citas**              | Botón para agendar vía WhatsApp. Atención solo con cita previa y en efectivo. |
| **Paquetes de Servicios** | Planes disponibles: <br> - 4 visitas por $250 <br> - 10 visitas por $500 (compartido en familia) <br> - Membresía única PMA: $10 |
| **Productos 4Life**    | Información sobre productos seleccionados de 4Life y sus beneficios para el sistema inmune. |
| **Ambit Energy**       | Breve sección sobre cómo ahorrar en electricidad o gas con consultas gratuitas. |
| **Contacto**           | Botón de WhatsApp y posible integración de ubicación o formulario simple. |

---

## 🎨 Diseño Visual

- Navbar vertical a la derecha.
- Fotografía de fondo que cubra toda la pantalla con filtro de transparencia.
- Animación de saludo tipo *typewriter* que aparece desde la izquierda hasta 3/4 del ancho de la pantalla.
- Transición de colores suaves que aparecen después de unos segundos.
- Estilo limpio, elegante y natural con colores sugeridos:
  - Verde salvia
  - Blanco cálido
  - Beige claro
  - Dorado suave

---

## 💻 Tecnologías sugeridas

- HTML5 + Tailwind CSS
- JavaScript (para animaciones)
- [Vite](https://vitejs.dev/) como empaquetador
- Integración de WhatsApp API para agendar citas
- Opción a futuro: React.js si deseas expandir funcionalidades

---

## 🚀 Objetivo

Crear una página profesional y acogedora donde los visitantes puedan:

- Conocer qué es la Neurobiótica
- Agendar fácilmente sus citas
- Ver promociones y paquetes disponibles
- Aprender sobre productos naturales que complementan su bienestar
